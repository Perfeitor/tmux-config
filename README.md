# tmux-config

Cấu hình tmux cá nhân, quản lý plugin bằng [TPM](https://github.com/tmux-plugins/tpm).

## Cài đặt

```bash
git clone <url> ~/tmux-config
cd ~/tmux-config
./install.sh
```

Mở tmux và nhấn `prefix + I` (prefix mặc định `Ctrl+b`) để cài plugin.

## Yêu cầu

- tmux >= 3.1
- git
- xclip (cho clipboard integration)
- Nerd Font (cho window name)
